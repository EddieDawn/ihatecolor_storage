# Day 8 — 클라이언트 디자인 피드백 반영과 다크 포토 저널 정리

> 작업일: 2026-08-28  
> 프로젝트: 웨딩 스냅 사진작가 포트폴리오 사이트

## 1. 작업 목표

Day 7에 완성한 Hero-only 랜딩, 사진 목록, 사진 상세 흐름을 바탕으로 클라이언트의 시각적 피드백을 집중 반영했다.

오늘의 핵심은 불필요한 문구와 UI를 제거하고, 사진 목록과 상세 화면을 동일한 오프블랙 계열로 연결하며, 작은 글자의 가독성과 사진 중심의 레이아웃을 다듬는 것이었다. 랜딩의 여백과 링크 위치는 여러 안을 비교한 뒤 기존 비대칭 구성을 유지하는 방향으로 최종 결정했다.

## 2. 랜딩 페이지 단순화

Hero 사진에 집중할 수 있도록 남아 있던 설명과 장식 요소를 추가로 제거했다.

제거 및 변경 범위:

- `Wedding Archive 2024—26`
- `I do. Still.` 제목과 소개 문장
- `Justyes gallery / Seoul, 2026`
- `A quiet wedding archive`
- 오른쪽 하단 구분선
- 대표 이미지 순번 `No. 001`
- 헤더의 `Gallery · Wedding stories`를 `Gallery`로 축약

랜딩 왼쪽 레일의 `Journal`, `Contact`, `Instagram`은 같은 너비의 텍스트·SVG 아이콘 구조를 사용해 화살표 끝의 세로축을 맞췄다.

### 2.1 여백과 사진 폭 검토

오른쪽 빈 공간을 보완하기 위해 다음 안을 순서대로 시험했다.

- Hero 좌우 열을 동일한 폭으로 만들어 사진 여백 대칭화
- 오른쪽 빈 열을 줄이고 사진 영역 확장
- 왼쪽 레일 링크를 검정 여백 안에서 수평 중앙 정렬

비교 결과 중앙 정렬과 사진 확장은 기존 구성보다 어색하다고 판단해 모두 원복했다. 최종 상태는 Day 7에서 사용한 비대칭 열 비율과 왼쪽 패딩 기준의 링크 위치를 유지하며, 이미지 순번만 제거한 형태다.

## 3. 사진 목록의 불필요한 UI 제거

사진 자체와 3열 그리드가 화면의 중심이 되도록 목록 화면의 부가 UI를 정리했다.

제거 범위:

- 사진 목록 전체 푸터
- `div.journal.toolbar` 전체
- 툴바의 `Journal` 제목과 페이지 카운터
- 사진 캡션 위 구분선

툴바가 사라지면서 페이지 제목 전달용 속성과 사용하지 않는 관련 스타일·스크립트도 함께 제거했다. 페이지네이션은 기존처럼 유지한다.

관련 커밋:

- `28674cf` — 사진 목록 푸터 제거
- `c74f5d3` — 사진 목록 툴바 제거와 랜딩 `Gallery` 문구 축약

## 4. 사진 목록을 오프블랙 화면으로 전환

랜딩은 검정이고 사진 목록은 밝은 색이던 투톤 구성이 애매하다는 피드백을 검토했다. 순검정 `#000000`보다 사진 사이트에서 부담이 덜한 오프블랙 `#11110f`를 선택했다.

사진 목록 팔레트:

```css
--paper: #11110f;
--ink: #f2f0eb;
--line: rgba(242, 240, 235, 0.28);
--muted: rgba(242, 240, 235, 0.66);
```

우선 배경과 기본 텍스트 색상만 다크 화면에 맞췄고, 캡션의 세부 시인성은 별도 조정 대상으로 남겼다.

관련 커밋:

- `ac0281b` — 사진 목록 오프블랙 배경 적용

## 5. 타이포그래피 가독성 개선

전체 화면에서 특히 버튼과 작은 대문자 글자가 흐릿하게 보이는 문제를 조정했다. 브랜드 인상을 크게 바꾸는 폰트 교체 대신 크기와 굵기를 제한적으로 높였다.

주요 변경:

- 작은 UI 글자를 주로 `11–12px` 범위로 확대
- 작은 본문과 메타데이터를 기본 `500`으로 강화
- 버튼과 내비게이션을 `600`으로 강화
- 랜딩과 사진 목록의 `Justyes` 워드마크는 과하게 무거워지지 않도록 이전 값인 `500`으로 복원

관련 커밋:

- `d746ffe` — 작은 글자와 버튼 가독성 개선

## 6. 사진 목록 그리드와 헤더 조정

Studio IVE의 Journal 화면을 참고하되, 사용자가 지정한 항목만 조정했다. 변경 범위는 좌우 여백, 가로·세로 격자 간격, 이미지 크기와 첫 이미지 시작점이며 나머지 디자인은 유지했다.

최종 데스크톱 기준:

- 헤더 높이: `140px`
- 목록 좌우 여백: `--journal-side: clamp(32px, 5.56vw, 80px)`
- 첫 이미지 상단: 1440×900 기준 `160px`
- 3열 가로 간격: `26px`
- 세로 간격: `52px`
- 카드 이미지: `3 / 4`, 1440px 화면에서 약 `404px` 너비

모바일 헤더는 `76px`, 목록 좌우 여백은 `18px`로 조정했다.

장소와 날짜가 모두 없는 카드에는 `—`를 출력하지 않고 빈 영역으로 둔다. 캡션의 좌우 배치는 유지하되 위쪽 구분선은 표시하지 않는다.

## 7. 사진 상세 화면 통일

사진 목록에서 상세로 이동할 때 배경 전환이 발생하지 않도록 상세 화면도 `#11110f` 오프블랙 배경과 밝은 텍스트로 변경했다.

상세 화면 변경 사항:

- 왼쪽 상단 `Photo detail` 문구 제거
- 가운데 작품명과 오른쪽 `Back to journal` 유지
- 사진을 원본 크기와 관계없이 이미지 영역의 가로·세로 중앙에 배치
- 작은 원본은 강제로 확대하지 않음
- 큰 원본은 비율을 유지하면서 화면 영역 안에 맞춤
- 장소와 촬영일이 모두 없으면 `—` 및 빈 `figcaption`을 렌더링하지 않음

이로써 저해상도 사진은 불필요하게 늘어나 화질이 더 나빠지는 것을 피하고, 큰 사진은 화면을 최대한 활용하면서 전체 구도를 보존한다.

## 9. 디자인 점검 결과

현재 구현을 랜딩, 사진 목록, 사진 상세 화면으로 나누어 다시 살펴봤다. 새로운 장식 요소를 추가하기보다 다음 문제를 우선 정리하는 것이 효과적이라고 판단했다.

우선 권장 사항:

1. 랜딩 대표 이미지 안의 타 브랜드 문구가 보이지 않는 최종 웨딩 사진으로 교체
2. 고양이 이미지와 `cat9` 같은 테스트 콘텐츠를 실제 포트폴리오 자료로 교체
3. 밝은 사진 목록 팔레트가 남아 있는 디자인 시스템의 일부 설명을 현재 오프블랙 구현과 완전히 통일
4. 구분선 제거 후 남은 캡션의 `margin`과 `padding`을 정리해 사진·제목 사이 간격 축소
5. 랜딩과 사진 목록에서 서로 다른 `Contact` 동작 통일
6. 운영체제별 타이포그래피 차이를 줄이기 위한 최종 웹폰트 결정

랜딩 오른쪽의 빈 공간은 별도 장식이나 메타데이터를 억지로 추가하지 않고 의도적인 비대칭 여백으로 유지하는 편이 현재 방향에 더 적합하다.
